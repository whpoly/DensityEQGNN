# 本地 NMC：周期修复后的表示能力与系数预测诊断

日期：2026-10-25。本次完成 8 个现有本地原始 NMC 样本、4 种表示的 32 次完整网格直接系数拟合；另完成 2 次补充拟合以覆盖统一 R16 配置，共 34 个主结果。没有训练新的 GNN，也没有产生新的官方测试集成绩。

**结论与下一轮选择**

当前 R12 原子基的平均 oracle NMAE 为 **0.26675%**，相同通道数的原点正则径向基为 **0.26857%**，正则原子基加键中心为 **0.23524%**。把接近相同的系数预算用于更密的原子径向基，得到 **0.15031%**，8 个样本均优于键中心方案。统一 R16 后平均为 **0.14526%**。下一轮优先检验“正则原子基＋统一 R16＋稳定的径向坐标”，保留现有 hidden l≤2、density l≤4 的骨干设置。键中心保留为后续消融，暂不优先增加角动量阶数或讨论效率。

这同时暴露了两个问题：现有 GNN 系数离当前基组已经实现的拟合精度还很远；更强的径向表示又能继续明显降低拟合误差。不能把二者归结为单一的“网络阶数不足”。这些 oracle 数字是实际找到的可行拟合误差，是最优拟合误差的上界，**不是经过认证的表示误差下限**。

**数据与度量**

使用 `data/nmc_cache/0.CHGCAR.lz4` 到 `7.CHGCAR.lz4` 的原始 DFT CHGCAR，读取 `total` 网格并除以晶胞体积转成密度；没有使用此前 SCF 测试中的机器学习初猜作为标签。每个样本的网格为 56×56×140，共 439,040 点；8 个结构共有 **3,512,320 个不同的完整网格点**。4 种表示使用完全相同的数据、周期像规则与评价点。

每个结构计算 `sum(abs(rho_fit-rho_DFT))/sum(abs(rho_DFT))`，再对 8 个结构等权平均。本文表格全部为百分数；原始 JSON 保存比值，需要乘 100。没有做电子数归一化修正、截断负密度或事后加原子基线。

这 8 个结构是本地可用的诊断集，尚未核实它们在官方训练/验证/测试划分中的归属。因此本次用于选方向的结果不能当作独立测试成绩；正式选超参数应迁移到确认的训练/验证诊断子集，保留测试集不参与选择。

**表示的定义与公平性控制**

原子展开均包含 l=0…4，cutoff 为 3 Å。当前径向函数为 `exp[-r²/(2σ²)] × (1+cos(πr/rc))/2`，σ 在 3/32 Å 到 3 Å 之间按几何级数取值。正则版本在第 l 阶乘以 `(r/σ)^l`，使 l>0 通道在原点消失，具有 solid-harmonic 所需的原点行为。

| 表示 | 原子部分 | 额外中心 | 每结构自由系数数 |
|---|---|---|---:|
| 当前基 | R12，原径向函数，l≤4 | 无 | 11,400–14,100 |
| 正则径向基 | R12，乘 `(r/σ)^l`，l≤4 | 无 | 11,400–14,100 |
| 正则基＋键中心 | 上述正则 R12 | 周期阳离子–O 配位中点，R4、l≤2、cutoff 2 Å | 14,424–19,068 |
| 增宽原子基 | 正则 R15 或 R16，l≤4 | 无 | 14,250–18,800 |

键中心从完整周期邻居中构造，阳离子–O 距离阈值为 2.6 Å，包含 Li–O 与过渡金属–O；中点折回原胞并去重。这里只是几何配位中点，不代表量子化学键级，不含 O–O、金属–金属、可学习浮动中心或二次密度展开。原子与键中心的密度都累加 cutoff 内全部周期像。

增宽原子基的 R 由键中心版本的系数总量配平：样本 4、6 为 R15，其余为 R16；与对应键中心方案的系数数量差为 −1.41% 到 +2.68%。这是表示自由度的近似控制，不是 GNN 参数量或运行时间的控制。R 改变时几何尺度网格也改变，R12 与 R16 不构成严格嵌套子空间，因此不能把结果解释为只增加四个完全独立通道的因果效应。

所有候选先按 `r² dr` 测度对径向函数做 SVD 白化，保留全部径向方向。这是可逆坐标变换，不改变各自的函数空间。当前基白化后与生产 PBC 解码器的等价性已通过测试。未对径向奇异值做隐式截断。

|---|---:|---:|---:|
| 4 | 0.17365% | 0.15549% | 15,200 |
| 6 | 0.17875% | 0.15651% | 15,200 |

统一 R16 的范围为 **0.12176%–0.15797%**。除这两个补充结果外，其余 6 个复用主实验中相同 R16 表示的结果，未重复计算。该方案不再强求逐结构与键中心系数数量配平，因此证明近似等预算优劣的是主表的 R15/16 对照，统一 R16 用于确定下一轮共同基配置。补充结果保存在 [固定 R16 目录](<C:/Users/User/Desktop/density EQGNN/runs/nmc_oracle_pbc_fixed_r16>)。

**表示误差与 GNN 系数预测：能分清到什么程度**

同一旧 checkpoint 在同一组 8 个完整网格上做三种算子对照：

| 系数来源与评价算子 | 平均 NMAE | 能说明什么 |
|---|---:|---|
| 旧原子图预测，旧单像密度重构 | 1.18190% | 旧模型在这 8 个结构上的历史行为 |
| 旧原子图预测，修复后的全像密度重构 | 1.19765% | 固定旧预测系数，仅改变解码器的影响 |
| 修复后的全像原子图预测，修复后的密度重构，仍用旧权重 | 26.36827% | 图算子改变后的权重失配 |
| 当前 R12 基，修复后的解码器，逐结构直接拟合系数 | 0.26675% | 同一个表示已实现的拟合精度 |

在修复后的同一个密度解码器下，旧图输出的系数为 1.19765%，自由拟合系数为 0.26675%，相差 **0.93089 个百分点**，约占前者误差的 **77.73%**。这是“现有预测系数未充分使用当前表示”的直接证据，不需要先更换基函数就存在改进空间。但不能把剩下的 22.27% 叫作不可约表示误差，因为这个 oracle 仍是上界。

26.37% 不能用作修复后 GNN 架构的精度结论。完整像让原子图的邻居和消息聚合发生实质变化，旧权重是在另一算子上学到的。必须从头训练修复后的图，再把其误差与相同表示的 oracle 比较。当前还没有这样的新 GNN，因此“修复后网络是否能逼近 oracle、泛化损失占多少”仍待训练验证。

更强原子基的可行拟合约为 0.12–0.18%，也说明可以继续改进表示；但没有认证下界，不能断言现有表示绝不可能低于 0.1%。此前公开 NMC 结果约 0.060% 可作为项目目标背景，来自不同的完整测试集，不能和本地 8 个逐结构拟合值组成同协议排行榜。论文结果及版本来源见 [此前的精度复核](<C:/Users/User/Desktop/density EQGNN/reports/pbc_fix_accuracy_review_2026-10-24.md>)。

**误差主要在哪里**

按最近原子距离分解，并以各结构贡献的宏平均计算份额：当前基约 **57.33%** 的 L1 误差来自 0.5–1 Å，**30.67%** 来自 1–2 Å，合计约 **88.00%**。增宽原子基把这两个区间对总 NMAE 的贡献分别从 0.15293、0.08181 个百分点降到 0.07785、0.05879 个百分点。

这解释了为什么只修改 r→0 行为没有解决主要误差。这里的距离分解不是成键区域分类，也不能分离纯径向误差与角向误差；结合近似等预算的原子/键中心对比，才支持当前的径向优先顺序。

32 个拟合在评价网格上均未出现负密度。平均绝对相对积分电子数偏差依次为 0.00524%、0.00254%、0.00314%、0.00730%。更低 NMAE 不自动保证更小电子数误差；后续训练应同时报告二者。网格上非负也不保证任意离网格位置非负。

**数值求解与结果的可信范围**

先在完整网格构造每个中心的紧支撑块，再用 float64 累积全局 Gram 矩阵及右端项得到预条件。`1e-9` ridge 用于可逆预条件与初始化，最终目标没有系数正则项。优化直接最小化归一化密度残差的平滑 L1，平滑尺度依次为 1e-3、1e-4、1e-5；每阶段最多 75 次 L-BFGS 迭代，最后额外 50 次 float64 精修。表格最终评价是不加平滑的 NMAE。

基函数在 float64 构造，完整网格块以 float32 存储；Gram、最终精修的矩阵乘积及伴随均为 float64。拟合完成后丢弃存储矩阵，用原始位置、晶胞和系数重新生成 float64 基函数，在所有网格点独立评价，而非只读取训练损失。

| 数值检查 | 结果与解释 |
|---|---|
| 存储矩阵与独立 float64 重构的 NMAE 差 | 32 个结果最大 0.0000147 个百分点，远小于候选间的主要差距 |
| 最后一次精修阶段的最大改善 | 增宽原子基为 0.001752 个百分点；其余方案不超过 0.000117 个百分点，说明更宽基仍更难优化 |
| sample 1 当前基更长全 float64 求解 | 0.2917975%，主实验为 0.2918223%，相差 0.0000248 个百分点 |
| 原始径向矩阵条件数 | 当前 R12 约 2.05×10⁵；正则 R12 最高 5.54×10⁵；正则 R16 最高 4.85×10⁸ |
| 数值对偶检查 | 最大 `abs(A.T @ u)` 约 1.47×10⁻⁵；数值 primal–dual gap 最高约 0.080 个百分点，不足以认证最优性 |

对偶向量仅经过数值投影，约束未精确满足，不能把其数值称作严格的误差下界，或者宣称已证明不同函数空间的最优误差排序。相同求解流程、逐样本一致的排序与独立精度复核为当前选择提供经验依据；更充分求解仍可能改变数值。

最初尝试 65,536 个随机点拟合，在 sample 1 当前基上，拟合点为 0.30999%，完整网格却为 2.45964%，未参与拟合的点为 2.83636%。因此主结果全部改用完整网格。不能用低采样拟合损失判断基组能力，也不能从这一次现象推断所有动态采样 GNN 都会失败。

此前旧 3 结构、有限优化 oracle 约 0.6705% 与本次数据、优化、周期算子均不同；本次降低不能全部归因于 PBC 修复。它首先更新了“我们已经找到多好的系数”这一事实，推翻了把旧数值当作表示精度下限的用法。

**下一轮训练按两个关口推进**

1. **先检查新算子的可学习性。** 用相同 8 个结构做小集合过拟合诊断，从头训练两组：修复 PBC 的原始 R12 基，以及正则 R16 基。固定 hidden l≤2、density l≤4、edge l≤2 和其余骨干设置，以密度监督为主。原始配置保留作对照。优先动态覆盖完整网格，周期性完整网格验证，不再仅反复抽取一个固定的小 probe 池。若做近核/成键混合采样，应按实际抽样概率加权，使优化目标与完整网格 L1 一致。

2. **能逼近 oracle 后再做完整训练。** 小集合过拟合的工程验收建议是：每种表示的 GNN 宏平均 NMAE 不高于其对应 oracle 宏平均的 1.2 倍，当前 R12 约为 0.3201%，正则 R16 约为 0.1743%；同时逐结构检查是否有明显失败样本，并确认多个随机种子趋势一致。这是诊断门槛，不是物理精度标准。若 R12/R16 都远高于 oracle，先定位损失尺度、优化器、采样、readout 和通道容量；若 R16 接近自身 oracle 但仍未达到项目目标，再做元素/l 相关尺度、稳定的其他径向族或更丰富密度展开的 oracle，之后才增加训练规模。

正式训练前需把正则径向函数和白化输出接入生产解码器，并验证值、梯度、旋转及原胞/超胞一致性。目前它们仅在本次 oracle 工具中实现，已有 PBC YAML 不会自动启用新基。尤其 R16 条件数很高，不能直接在 float32 中把巨大的白化变换乘到相消的原始 Gaussian 上；先使用 float64 计算径向特征后转存，或实现经数值等价验证的稳定计算。跨结构全局 Gram 仅用于 oracle 求解，不是 GNN 必须预测的坐标；GNN 使用各 l 内相同、固定的径向变换，保持等变性。

不要直接用病态原始系数的普通 MSE 取代密度损失；重叠中心的系数并非天然唯一或等权。若用 oracle 系数辅助监督，需先明确坐标、度量及空空间处理。新模型从头初始化，旧 checkpoint 不续训，也不沿用旧 best 验证值。

当前完整 NMC 数据根目录尚未恢复，本次没有启动长程完整训练。恢复数据后，再使用已确认的官方训练/验证划分运行上述胜出方案，与修复 PBC 的原始 R12 基对照；独立测试集只在方案固定后评估。阶段目标仍以完整测试集 <0.1%、再接近公开约 0.06% 为参考，暂不把效率作为主要研究结论。
