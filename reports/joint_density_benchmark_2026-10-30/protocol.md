# Unified NMC density and PAW inference benchmark

This is a local engineering and small-data generalization benchmark, not a reproduction of either paper's large-data benchmark. Preserve all prior code, checkpoints, splits, and results. No new fitting of model weights. All new numerical optimizations are developed on training structure cache_0 and synthetic geometry; candidate choice uses ONLY validation structures SCF 170 and 314.

Reuse density encoders trained on cache 0–7. Reuse the fixed PAW split: eight training structures, two validation structures (170/314), five test structures (361/796/825/1056/1749). Historical SCF 1/3/6 duplicate training structures and stay excluded. Prior tests are known from earlier experiments; this is not a blind test. Report seen-structure spatial holdout separately from full-grid error on unseen structures. Never mix their means.

Primary density accuracy criterion: validation macro full-grid NMAE <= 1.01 times complete DeepDFT. Secondary relaxed criterion: <= 1.05 times DeepDFT. Speed goal: fresh complete density+PAW inference <= 1.10 times Eden density+independently fine-tuned Eden PAW, measured in this run. This is an acceptance target, not a promise of attaining it. Select fastest eligible candidate using validation only, then lock selection before evaluating test metrics. Report every predetermined candidate, including failures, in the final comparison, with clearly labeled selected candidates.

Fixed variants:

- deep_reference: existing complete FlatProbe, chunk 4096.
- deep_factored: algebraically factored complete FactoredProbe, chunk 4096.
- deep_table: full-grid radius-4 model with a 16385-point linearly interpolated radial-filter table, chunk 4096.
- deep_fused: same table, one CUDA kernel for each layer's edge message generation and CSR aggregation, chunk 8192.
- fused_cubic_r3, fused_cubic_r3.25, fused_cubic_r3.5: same fused operator plus periodic cubic far-field interpolation, stride 2, transition width 1 Angstrom, respective exact-near support radii, chunk 8192.
- eden: pinned official local Eden density model plus separate fine-tuned PAW model.

Tables contain only deterministic functions of already-trained weights and distance; no density or PAW labels. Preserve float32 inference, original 3x128 DeepDFT states, 4 Angstrom original cutoff, original readouts and atom encoder. CUDA fusion uses no reduced precision or learned cache. Validate fused versus PyTorch table outputs and table versus original radial filters and full predictions, including zero distances, cutoff boundaries, no-neighbor queries, changed atom features/positions/elements, and periodic grids. Capture compiler options and CUDA source hashes. If numerical audits fail, repair implementation before validation and retain diagnostic logs; do not tune on test results. No training or extrapolating unsupported PAW components.

Joint DeepDFT inference shares ONE fresh atom-encoder pass between density and both PAW heads (report the two head predictions separately, never average predictions as an ensemble). For deployment timing, use seed 42 fixed in advance; seed 43 is an accuracy/reproducibility check outside timing. Eden density and fine-tuned occupation encoders are independent, so include both. Reuse constant model weights and lookup tables, but refresh all geometry, SAD, atom states, interpolation fields, density and PAW outputs on every timed call. Model/constant-table/kernel initialization and input-file loading are excluded from steady-state timing and reported separately. Do not conflate head-only time with total inference.

Run each variant in a fresh process, one GPU job at a time. Two warmups and five synchronized wall-time repetitions per structure in formal evaluation; median within structure then macro average, plus pooled p90, all repeats, allocated absolute/incremental peak and reserved peak. Delete outputs before the next call. No timed error calculation, disk writes, or ground-truth access inside prediction. Measure density-only and joint paths separately; report kernel/model setup time. Use immutable model-input mappings without target fields. All eight old training structures and seven holdout structures use original full grids.

Density metrics: macro and pooled full-grid NMAE, MAE/RMSE, absolute charge bias, negative-density integral, errors by distance-to-nearest-atom bands; old spatial train/val/test metrics remain separately labeled. PAW: same L<=2 masks, normalization and coefficient MAE/relative L1 as the completed PAW experiments, both seeds, by angular rank. All underlying targets and checkpoint hashes must remain unchanged. L=3/4 labels remain unavailable and excluded. PAW relative L1 is NOT density NMAE.

Scaling diagnostic: deterministic cache_0 periodic replicas 1x1x1, 2x1x1 and 2x2x1, fixed grid spacing. This checks compute/memory growth and periodic consistency, not independent chemical generalization. Run reference, Eden and the validation-selected strict candidate, report OOM rather than silently changing chunk size/precision. Compare repeated target density and PAW labels, while labeling replication metrics as diagnostic. A local VASP executable/WSL installation is unavailable; therefore actual SCF iteration counts, total DFT time, energies/forces, and complete high-rank PAW initialization remain explicitly unverified. A larger cross-material dataset remains separate scope.

Pre-validation numerical amendment: the initial 8193-point table passed full-density agreement on training geometry but one of 12.6 million filter comparisons exceeded the 5e-5 absolute + 5e-5 relative tolerance (absolute difference 5.54e-5). Double table resolution to 16385, keeping the same numerical acceptance checks. Preserve the initial table implementation and failure log. No validation/test candidate metrics had been read. Initial exact-bitwise PAW equality was also inappropriate for the original CUDA reductions (max difference 2.86e-6); use rtol=2e-4, atol=2e-5 and additionally relative L1<1e-6, recording the differences. This changes neither model weights nor PAW implementation.
