# DeepDFT 固定权重推理与复用测试

范围：既有 NMC 0–7、每结构 439040 点，固定 deepdft_eight/best.pt，不重新训练。
原始 2048 查询分块接口是数值参照。试验仅根据时间和与参照的数值一致性选择实现，
不根据 DFT 测试误差调模型或选择近似；空间测试误差只复核既有结果。

候选：官方接口增大查询块；规则网格局部 stencil 构图；移除单结构打包/拆包同步；
原子侧消息投影每结构一次；查询网络固定容量 CUDA Graph 重放。
禁止直接复用变化结构的原子/查询特征或密度。TF32 关闭、网络 float32，与原权重一致。

同一结构先用样本 0 做分块吞吐预实验，再固定分块设置，在 8 个结构上验证完整场。
比较所有周期边的多重集，以及完整场最大绝对差、相对 L1 差和原测试点 NMAE。
容许浮点求和次序差异；预定一致性门槛为相对 L1 < 1e-6、逐点 atol=5e-5, rtol=3e-5。
不会把近似插值或重新训练混入本轮结果。

计时 CUDA 显式同步，正式候选交错重复至少 3 次，先预热；报告每结构重复中位数及其宏平均。
新输入完整计时包含原子图、原子网络、查询几何、完整查询网络；文件/模型加载另列或排除。
缓存几何与已有执行图的计时明确标记，首次录制成本单独计入冷启动和摊销分析。
分段同步诊断不与无插桩总耗时混用。

相邻帧实验：固定晶胞和网格，对所有原子施加预定小位移，候选邻域含 0.2 Å skin，
超出 skin/2 或晶胞/网格改变必须失效。原子特征、距离、方向和密度全部重新计算。
用扰动结构的官方全量计算验证，不用原结构 DFT 标签评价扰动结构精度。
这是合成位移复用验证，不是真实 MD 加速或未知结构密度精度验证。

仅已有 8 个结构的实现诊断；不推断 SCF 总时间或跨结构泛化。

## 追加诊断（在其执行之前固定）

1. 以连续 query 分段求和替代原子到查询点的 atomic scatter。先在结构 0 上核对
   全网格输出和吞吐；这是相同数学模型的计算顺序实验，结果单列。
2. 固定每轴 stride=2，即仅在 1/8 的规则网格点运行同一网络，随后做周期三线性插值。
   固定两个版本：直接插值总密度；在粗点扣除 GPU SAD，插值残差后加完整网格 SAD。
   该近似诊断不进入主表的无损结论，不改变权重，不调节 stride 或插值方式。
   检查粗网格节点值、完整场相对原模型误差及原空间测试 NMAE；同进程交错重复 3 次。
   这是已公开空间基准上的探索性结果，尚不代表新结构精度。
