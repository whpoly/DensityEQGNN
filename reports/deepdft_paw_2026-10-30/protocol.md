# DeepDFT PAW occupation readout: pilot protocol

Target: VASP nonmagnetic on-site augmentation coefficients in their real spherical tensor representation, not band occupations or a density-grid NMAE. Preserve all existing density checkpoints and inference implementations.

Available data audit: local NMC cache 0–7 supplies eight training structures. The ten pre-existing SCF oracle_full CHGCAR files contain three exact geometry duplicates (IDs 1,3,6); exclude these. Use remaining numeric IDs 170,314 for validation, and 361,796,825,1056,1749 for test. Check hashes and periodic structure equivalence. No grid-point or individual-coefficient random split. These five structures were not used to train the eight-structure DeepDFT checkpoint. This is a small pilot, not a broad material-generalization claim. Inspecting raw labels is limited to schema, shape, and angular-rank availability before training.

All available files contain nonzero L=0,1,2 and identically zero L=3,4 slots. The source LMAXMIX is not independently established; zero higher ranks must be treated as unavailable information, not evidence of zero physical values. Train and evaluate only L<=2; exclude all absent element/projector channels and L>2 from metrics. Do not claim complete d-channel PAW initialization at LMAXMIX=4. Parse projector l/order from local Li, O, Mn, Co, Ni POTCAR Non local Part blocks; retain hashes. CHGCAR dimensions match these projectors but do not identify the exact original POTCAR version, which remains a provenance limitation.

Freeze the existing 3x128 DeepDFT checkpoint. Concatenate scalar/vector features from its three atom layers. A new invariant edge MLP uses atom scalars, projected vectors, and radial geometry; multiply its weights by real spherical harmonics and sum at atoms to obtain equivariant augmentation tensors. Add an invariant onsite readout for L=0. This is a new PAW head, not the original DeepDFT architecture and not a full EdenGNN reproduction. All added operations occur on atoms/atom-neighbor edges; no probe-grid inputs or target-derived features.

Baseline: training-element mean of each L=0 coefficient, with all L>0 components zero. Target scaling is per element and tensor block, with a shared RMS scale for all m, floor 1e-3. All mean/scale statistics use only training labels. Loss: mean squared standardized error over native L<=2 coefficients, averaged across the sampled structures. Adam, lr 1e-3 down to 1e-5 cosine, 6000 updates per seed, batch 2 structures, gradient clipping 5. Seeds 42 and 43. Evaluate every 200 steps; select each seed's checkpoint by validation mean per-structure raw coefficient MAE. Freeze selection before evaluating test; report both seeds without test-based selection or tuning.

Metrics: mean absolute coefficient error (dimensionless), RMSE, sum absolute error / sum absolute target value, and breakdown by L and element. Report anisotropic L>0 separately so large isotropic terms cannot hide failure. Relative L1 of occupation coefficients must not be called density NMAE or compared numerically to density error. Report both per-structure macro and coefficient-pooled metrics. Compare each seed with the training-only baseline.

Checks: raw-to-canonical-to-native coefficient roundtrip; source-density text unchanged during augmentation replacement; masked ranks excluded; nontrivial rotation/inversion/translation equivariance; finite gradients; serialized predictions and checkpoint reload; frozen encoder/checkpoint hash and unchanged full-grid density on eight original structures. Time PAW head alone and encoder+head on all five test structures with fresh atom graph/features for total timing. No cached learned features during timed deployable inference. Test frozen head rotation consistency on actual features.

No VASP run or SCF-speed claim in this experiment. Occupation-only export preserving a reference density is diagnostic, not an ML-only prediction. A deployable output must replace the smooth grid as well and needs complete, consistent PAW labels.
