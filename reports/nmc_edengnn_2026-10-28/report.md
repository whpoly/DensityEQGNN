# EdenGNN / R16：8 个 NMC 结构的配对诊断

本轮使用相同的结构 0–7、每结构 439,040 个网格点、原 80/10/10 空间划分，以及同一 RTX 5060 Ti。空间测试点来自已见结构，不代表未知结构泛化。

## 主要结果

| 指标 | EdenGNN 密度分支 | 当前 R16 |
|---|---:|---:|
| 测试 NMAE，逐结构宏平均 (%) | 0.2848 | 2.0607 |
| 新结构完整网格推理 (s) | 1.1277 | 5.3005 |
| 新结构推理 P90，合并全部重复 (s) | 1.2047 | 5.6047 |
| 复用几何后的完整网格推理 (s) | 0.9737 | 3.4064 |
| 新结构推理峰值增量显存 (MiB) | 2240.0562 | 1316.7788 |

R16 / EdenGNN 新结构耗时比为 **4.70**。NMAE 定义为 Σ|预测−DFT| / Σ|DFT|；先在各结构测试点计算，再取算术平均。

每个结构预热 1 次，重复 5 次。表中时间为“各结构重复中位数的平均值”；P90 是全部 40 次观测的分位数。新结构时间包含原子图、网格几何和 EdenGNN 的 SAD 构造；模型及 POTCAR 文件加载另列。CHGCAR 读取含真值标签，仅作数据管线诊断，不作为推理输入要求。

### 瓶颈与后续优先级

R16 的网络（含输出头）为 0.01108 s，网格几何为 1.81061 s，重构为 3.42998 s。应根据这些实测量级决定下一步，不能仅凭“每个原子输出少量系数”推断完整密度场会更快。

1. 首先优化 R16 的网格重构：减少小块循环和重复球谐/径向计算，缓存常量，核查白化矩阵能否先作用于每原子系数，再进行逐点收缩。代数重排必须比较密度与梯度误差；当前高条件数基组需要 float64，不能直接降到 float32 并假定精度不变。
2. 针对规则周期网格，优化原子到局部网格的候选生成及周期折回，避免反复扫描全部探针。是否采用 KD-tree 要由本轮计时决定，不能把预缓存成本省略。
3. 精度方面，将“系数预测误差”和“基组表示误差”分开。若更换数值更稳定的基组或引入 SAD 残差，需要独立训练和消融；这些属于下一轮模型工作，本轮没有用测试结果调参。
4. 完整场密度预测达到精度与速度目标后，再进行 VASP 初始化/SCF 对照，检验密度质量是否实际减少迭代，以及总 DFT 时间是否下降。

## 对照的模型差异

| 项目 | EdenGNN 密度分支 | 当前 R16 |
|---|---|---|
| 参数量 | 6,194,410 | 521,472 |
| 每原子密度输出 | 4 × 49 = 196 个系数 | 16 × 25 = 400 个系数 |
| 径向表示 | 按元素学习的径向 MLP | 固定高斯径向基 + 分阶白化 |
| 密度角动量截断 | l ≤ 6 | l ≤ 4 |
| 密度邻域 | 最近网格点中心的 4 Å 原生 stencil | 真实原子中心 3 Å cutoff |
| 起点 | POTCAR 推导的 SAD + 学习残差 | 学习的元素标量基线 + 系数预测 |
| 解码浮点精度 | float32 | float64（最后输出 float32） |

因此本轮公平性是同数据、同划分、同硬件与同更新/采样预算；并未控制参数量、物理先验、函数空间或解码精度。结果可评价当前两个实现的实用表现，不能独立归因于某一架构选择。

## 可复核性与边界

- EdenGNN 官方代码 commit `3be8c06265c02ecf1ef0587500ee9b8e091186ef`；原版 Encoder / DensityLayer，原版周期 stencil，未运行 PAW 分支。
- 参数量：EdenGNN 6,194,410；R16 521,472。两者均为 16,000 次更新、每步 1,024 训练点，训练顺序与采样 RNG 对齐。不是等参数量、等训练计算量或论文原始训练协议。
- Eden 最佳验证步骤 16000，固定验证子集 NMAE 0.28380%。只依据验证集选择，随后冻结 checkpoint 再评估测试。
- Eden 的 SAD 由本地 POTCAR 原子 form-factor 构造，不拟合目标密度；尚未与 VASP 原生零步密度逐点核验。这一适配限制意味着结果应称为“官方密度分支在本数据协议下的复现”。
- 两个网络 float32，TF32 关闭；Eden 重构 float32，R16 白化重构 float64。此差异属于当前实现，不能把时间差全部归因于模型数学结构。
- 训练结束后串行计时，CUDA 显式同步；显存增量排除已驻留模型和输入。绝对峰值包含两个驻留模型，原始 JSON 保留。
- 训练中使用经全参数梯度审核的 CUDA Graph 执行加速；正式推理在独立进程使用原版 eager 前向。恢复步骤和审核记录见 execution_acceleration*.json；训练调度速度不作为本轮模型推理对比结果。
- 本轮是单种子、8 个已见结构的空间插值诊断；既有测试结果已公开。不能据此声称跨结构泛化或统计显著性。
- 本轮未测 VASP SCF 步数或总时间，尚不能据密度预测加速断言 DFT 整体加速。
